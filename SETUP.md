# Setup

This package is for the `Hari-r31/Hari-r31` profile repository.

1. Copy the files into `github.com/Hari-r31/Hari-r31`.
2. Make sure GitHub Actions are enabled.
3. Open **Actions → Generate GitHub Metrics → Run workflow**.
4. Open **Actions → Generate Contribution Snake → Run workflow**.
5. The workflows generate the SVG assets automatically.

The main dashboard is generated by `lowlighter/metrics` and stored locally at `profile/metrics.svg`, so the README does not depend on `metrics.lecoq.io`.

If you later need private repository or organization data, replace `secrets.GITHUB_TOKEN` with a suitable GitHub token stored as an Actions secret. Never put tokens directly in the README or workflow.
